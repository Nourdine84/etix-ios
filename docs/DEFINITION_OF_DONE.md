# Definition of Done — eTix

Checklist appliquée à la clôture de chaque feature, avant tout merge vers `develop`.

## Qualité
- [ ] Build Xcode vert
- [ ] Aucun warning bloquant
- [ ] Tests unitaires / UI adaptés si nécessaire
- [ ] Feature validée fonctionnellement

## Compatibilité
- [ ] Light Mode
- [ ] Dark Mode
- [ ] iPhone SE
- [ ] iPhone Pro Max
- [ ] Dynamic Type

## Architecture
- [ ] Aucun code mort
- [ ] Aucune duplication inutile
- [ ] Respect du Design System
- [ ] Pas de régression connue

## Git
- [ ] Conventional Commits
- [ ] Branche conforme au Git Flow
- [ ] Historique propre

## Documentation
- [ ] Fiche de clôture générée
- [ ] ADR ajouté si décision d'architecture
- [ ] Roadmap mise à jour

## Dette
- [ ] Dette corrigée OU tracée dans `ROADMAP.md` avec priorité

## Validation
- [ ] GO MERGE validé
